# Politique de sécurité

## Signaler une vulnérabilité

Ne publiez pas de détails exploitables dans une issue ou une discussion publique.

Utilisez le signalement privé de vulnérabilité GitHub du dépôt :
https://github.com/zallyx62/IMPACT-/security/advisories/new

Si le signalement privé n'est pas disponible, contactez les responsables du dépôt par un canal privé GitHub avant toute divulgation publique. N'incluez pas de données personnelles ou de secrets qui ne sont pas nécessaires pour comprendre le problème.

## Informations utiles

Un signalement peut préciser :
- la version ou le commit concerné ;
- les étapes minimales pour reproduire le problème ;
- l'impact observé et les conditions nécessaires ;
- une proposition de correction, si elle existe.

N'effectuez pas de tests sur des systèmes ou comptes qui ne vous appartiennent pas et ne tentez pas d'accéder à des données d'autres personnes.

## Traitement

Le projet est bénévole et ne garantit actuellement aucun délai de réponse ni de correction. Les signalements seront examinés selon leur gravité et les moyens disponibles. Une correction pourra être publiée après vérification et préparation d'une mise à jour.

## Périmètre

Cette politique concerne le code et les configurations du dépôt IMPACT. Elle ne constitue pas une garantie de sécurité de l'hébergeur, du navigateur, du système d'exploitation ou des services tiers.
