# Code de conduite

## Objectif

IMPACT accueille les contributions qui améliorent la compréhension, la vérification et la transparence des informations. Les échanges doivent rester respectueux, accessibles et centrés sur le travail.

## Comportements attendus

- Critiquer les idées, les sources et le code, jamais la dignité des personnes.
- Expliquer les désaccords avec des éléments vérifiables et un langage respectueux.
- Reconnaître les incertitudes, corriger les erreurs et accepter les corrections.
- Respecter les personnes quelles que soient leur origine, leur identité, leur situation ou leurs convictions.
- Protéger les données personnelles et la vie privée.
- Déclarer les conflits d'intérêts pertinents dans les contributions éditoriales.

## Comportements inacceptables

- Harcèlement, menaces, intimidation, insultes ciblées ou discrimination.
- Publication d'informations privées, de coordonnées personnelles ou de secrets.
- Accusations factuelles graves sans éléments vérifiables.
- Manipulation volontaire de sources, falsification de preuves ou présentation délibérément trompeuse d'une information.
- Spam, publicité non sollicitée ou détournement répété des espaces de contribution.

## Modération et signalement

Signalez un comportement problématique aux responsables du dépôt par un canal privé GitHub. Ne republiez pas les données privées ou les éléments sensibles dans une issue publique.

Les responsables peuvent demander une correction, masquer un contenu, fermer une discussion ou limiter les contributions en cas de comportement contraire à ce code. Toute mesure doit être proportionnée et tenir compte du contexte.

## Portée

Ce code s'applique aux issues, pull requests, discussions et autres espaces utilisés au nom du projet IMPACT.
